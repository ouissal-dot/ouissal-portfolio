## 📌 About the Project

This is a simple and responsive portfolio website built using **HTML, CSS, and JavaScript**.  
It is designed to present my work, skills, and contact information in a clean and modern way.

## ✨ Features

- 📱 Fully responsive design (mobile-friendly)
- 🎨 Clean and modern UI
- 🧑‍💻 Sections for skills, projects, and about me
- 📩 Contact section (more features coming soon)
- ⚡ Lightweight and fast (no frameworks)
